I hope this to be a summary of the current version of my new website, and why I start making a website. 

# Why this page exists 
Quite simple: It looks fun to make a website. I mean, when I look at others' portfolio websites that are extremely cool, I have a inner impulse that I should make my own website also, so I made it. It wasn't that I need a developer portfolio like other does. It is just for me to practice on some framework, and also maybe as my little garden to express my feelings or what. 
# Design
This page aims to find a balance between a personal website and a developer portfolio. I hope the site is not too commercial that is too professional for personal site, while keeping this site as a usable portfolio to the employers.

## Fonts
This site uses Open Huninn Font, which is available at Google Fonts. This font has a rounded terminal, which seems to fit this site. Also it has a great support to most of the Asian characters like Chinese and Japanese. Previous version of this site uses Jetbrains Mono but it might looks not that natural enough.
